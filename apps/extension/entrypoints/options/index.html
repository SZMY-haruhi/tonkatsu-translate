General

常规

设置翻译语言、网页显示方式和划词行为。

语言

源语言建议保持自动检测。

网页显示

替换模式兼容性更好；双语模式仍在持续优化。

划词翻译

开启后按住 Alt 并松开鼠标才显示译文，避免干扰复制。

Provider

翻译引擎

每种引擎保存独立配置，切换时不会再互相覆盖。

DeepL

必须填写 API Key；Free 与 Pro 使用不同端点。

在 DeepL API 申请密钥；Free 密钥通常以 :fx 结尾。

MyMemory

无需注册或 API Key，适合少量临时翻译。

匿名服务约限制为每个 IP 每日 5000 字符，速度与质量不保证。MyMemory 不提供源语言自动检测；选择“自动检测”时扩展会按文字脚本进行基础推断。

LibreTranslate

请填写你可访问的自建服务地址。

OpenAI 兼容 API

仅用于云端 API；本地模型配置在独立引擎中。

兼容 Chat Completions 的云服务均可使用，接口地址一般填写到 /v1。

本地模型

选择运行时会自动填入默认地址；模型名仍需与你本机一致。

API Key 仅保存在本机浏览器中，不会进入安装包或项目代码，也不会通过 Chrome 账号同步；卸载扩展或清除扩展数据后会删除。建议使用有限额的 Key。

Sites

站点规则

默认允许所有站点；需要限制时再启用白名单设置。

站点列表规则

保存后刷新目标网页。未列出的站点会同时禁用整页翻译和划词翻译。

Advanced

高级

通常无需修改；这些设置主要面向 AI 引擎与性能调优。

并发请求

实际控制同时进行的翻译批次数；本地模型与 MyMemory 会自动限制到最多 2。

保留词

OpenAI 兼容与本地模型会将这些专名写入提示词。

DeepL 与 LibreTranslate 不保证严格保留这些词。
